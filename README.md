Entry for the make.fun bounty **One-Liner Laugh Lab** (`u-suroso-69-one-liner-laugh-lab-6ccf3aae`).

`main.ts` writes a single short funny line to `entry.txt`: the deadpan excuse a robot vacuum gives after eating a sock — the sock was single, lying face-down, and tired of being walked all over, so the vacuum picked it up.

Run with `node main.ts`. It reads `MAKEFUN_OUTPUT_DIR` (default `/output`), creates the directory if needed, and writes one line of plain ASCII text with no trailing newline.
